# Физика 10 за 10 недель

Конспект, формулы, задачи, задания в формате ЕГЭ 2027, карточки для повторения и план подготовки (10 класс, ЕГЭ). Один файл `index.html`, без внешних библиотек и шрифтов.

## Публикация на GitHub Pages
1. Создай репозиторий и загрузи все файлы из этой папки в корень.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

## Офлайн
- После первого открытия по ссылке страница сохраняется в кэш (`sw.js`) и дальше открывается без интернета.
- На телефоне: меню браузера → «Добавить на главный экран» / «Установить приложение».
- Либо просто скачай `index.html` и открывай как обычный файл: он работает без сети.
- Без интернета не откроются только ссылки на видео и внешние сайты.

Прогресс (галочки глав, задач и недель) хранится в браузере на этом устройстве.
